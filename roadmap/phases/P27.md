# P27 — Steadfast কুরিয়ার (Edge Function + ওয়েবহুক)

- **রেফারেন্স (MASTER-ROADMAP):** ফেজ ৬ (কুরিয়ার), ৮.৬
- **আগে পড়ুন:** `roadmap/00-RULES.md`, `roadmap/MIGRATIONS.md`, সর্বশেষ ২টি রিপোর্ট
- **মাইগ্রেশন নম্বর:** 033+

## কাজ
1. Edge Function `courier-steadfast`: কনসাইনমেন্ট বুকিং। শুধু অ্যাডমিন/সেলার-রোল, ইনপুট ভ্যালিডেশন, CORS শুধু নিজের ডোমেইন।
2. ওয়েবহুক Edge Function: সিক্রেট/সিগনেচার যাচাই, **idempotent** (ইভেন্ট টেবিল `courier_events`, ইউনিক ইভেন্ট ID, মাইগ্রেশন 033+), অর্ডার স্ট্যাটাস অটো-আপডেট।
3. key শুধু `Deno.env.get('STEADFAST_*')`। মক রেসপন্স দিয়ে টেস্ট লিখুন; আসল API কল নয়।
