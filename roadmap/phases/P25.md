# P25 — অর্ডার স্টেট মেশিন (মাইগ্রেশন 028)

- **রেফারেন্স (MASTER-ROADMAP):** ফেজ ৬ (প্রথম পয়েন্ট), ঝুঁকি ৩
- **আগে পড়ুন:** `roadmap/00-RULES.md`, `roadmap/MIGRATIONS.md`, সর্বশেষ ২টি রিপোর্ট
- **মাইগ্রেশন নম্বর:** 028

## কাজ
1. বর্তমান কনস্ট্রেইন্ট `pending|processing|completed|cancelled`। নতুন মান `confirmed, shipped, delivered, returned` যোগ, **পুরোনো মান না ভেঙে** (`processing`≈প্যাকিং, `completed`≈`delivered` ম্যাপিং)।
2. কনস্ট্রেইন্ট পুনর্গঠন `DROP CONSTRAINT IF EXISTS` + `ADD CONSTRAINT`। বিদ্যমান অর্ডার অক্ষত।
3. অবৈধ ট্রানজিশন ডিবি-ট্রিগারে বাধা (`Pending → Confirmed → Shipped → Delivered`, + `Cancelled/Returned`)।
4. `orders`-এ কুরিয়ার কলাম (consignment_id, tracking_code, courier, shipped_at) additive।
5. UI-তে স্ট্যাটাস লেবেল ম্যাপিং হালনাগাদ।
