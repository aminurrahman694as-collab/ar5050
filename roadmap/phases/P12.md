# P12 — R2 ফ্রন্টএন্ড: আপলোড ও প্লেব্যাক

- **রেফারেন্স (MASTER-ROADMAP):** ফেজ ৩, ১.৩ (সাইজ লিমিট)
- **আগে পড়ুন:** `roadmap/00-RULES.md`, `roadmap/MIGRATIONS.md`, সর্বশেষ ২টি রিপোর্ট
- **মাইগ্রেশন নম্বর:** নেই

## কাজ
1. আপলোড ফ্লো: ব্রাউজার → `r2-presign` → সরাসরি R2। ফ্ল্যাগ বন্ধ থাকলে বিদ্যমান Supabase আপলোড (ফলব্যাক)।
2. ভিডিও URL রেজলভার `storage_provider` দেখে; পুরোনো ভিডিও না ভাঙে।
3. `reelLimits.ts` **২৫ MB / ৬০ সেকেন্ডেই** থাকবে; ক্লায়েন্ট, বাকেট, ডিবি তিন জায়গার সংখ্যা মিলিয়ে রিপোর্টে লিখুন।
4. ফিডের ভিডিও ট্যাগে প্রিলোড/লেজি লোড যাচাই।
