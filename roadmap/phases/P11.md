# P11 — R2 ব্যাকএন্ড: presigned URL (মাইগ্রেশন 027)

- **রেফারেন্স (MASTER-ROADMAP):** ফেজ ৩, ৮.৫
- **আগে পড়ুন:** `roadmap/00-RULES.md`, `roadmap/MIGRATIONS.md`, সর্বশেষ ২টি রিপোর্ট
- **মাইগ্রেশন নম্বর:** 027

## কাজ
1. Edge Function `r2-presign`: লগইন + অ্যাভাটার + ব্যান + কিল-সুইচ চেক, দিনে ১০ রিল রেট-লিমিট, ফাইল টাইপ ও সাইজ (২৫ MB) সীমা, ইউজারভিত্তিক পাথ, UUID ফাইলনেম, মেয়াদ ~১০ মিনিট, CORS শুধু নিজের ডোমেইন।
2. R2 secret শুধু `Deno.env.get(...)`; কোডে মান নয়।
3. মাইগ্রেশন 027: `reels.storage_provider` (`supabase`/`r2`, ডিফল্ট `supabase`) additive।
4. R2 সেটআপ গাইড `docs/r2-setup.md`-তে (বাকেট, কাস্টম ডোমেইন, পাবলিক লিস্টিং বন্ধ, ক্যাশ হেডার `public, max-age=31536000, immutable`)।
