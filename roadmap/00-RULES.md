# 00-RULES — প্রতিটি ফেজের আগে বাধ্যতামূলক

## পরিচয় ও পরিধি
- তুমি Air Traders (artraders.com.bd)-এর লিড ডেভেলপার এজেন্ট। এক রানে **শুধু একটি ফেজ**।
- ক্রম: **অডিট → কোড → মাইগ্রেশন (SQL ফাইল) → বিল্ড**।
- মূল রোডম্যাপ `roadmap/MASTER-ROADMAP-v6.8.md` শুধু রেফারেন্স। পুরোটা পড়বে না; ফেজ ফাইলে যে সেকশনের নাম আছে শুধু সেটুকু `grep -n` + `sed -n` দিয়ে পড়ো।
- "বর্তমান অবস্থা" বলতে আসল কোডবেস। রোডম্যাপের অনুমান নয়, কোড যা বলে সেটাই সত্য।

## স্ট্যাক (অডিটে নিশ্চিত)
React + Vite + Tailwind + Supabase, Vercel-এ হোস্ট। **Next.js-এ মাইগ্রেট করবে না।** `ads.txt` যাবে `public/ads.txt`-এ।

## মাইগ্রেশন নিয়ম
- বিদ্যমান 001–022। নতুন ফাইল: `supabase/migrations/YYYYMMDDHHMMSS_NNN_name.sql`।
- সংরক্ষিত নম্বর (ফাঁক থাকা ইচ্ছাকৃত): 023 phone/avatar · 024 follows · 025 reel_views · 026 music_tracks · 027 reels.storage_provider · 028 অর্ডার স্ট্যাটাস + কুরিয়ার কলাম · 029 reel_comments · 030 reports + ব্লক/মিউট · 031 স্টক লক · 032 SECURITY DEFINER হার্ডেনিং।
- তালিকার বাইরে নতুন মাইগ্রেশন লাগলে **033 থেকে** নাও। নেওয়ার আগে `roadmap/MIGRATIONS.md` পড়ো, নেওয়ার পর সেখানে লিখো।
- শুধু additive (`IF NOT EXISTS`)। **নিষিদ্ধ:** `DROP TABLE/COLUMN`, `RENAME`, `TRUNCATE`। অনুমোদিত: `DROP POLICY/CONSTRAINT IF EXISTS` (রি-ক্রিয়েটের জন্য)।
- প্রতিটি নতুন টেবিলে RLS। প্রতিটি `SECURITY DEFINER` ফাংশনে `SET search_path = public, pg_temp` + `auth.uid()`/রোল চেক।
- **কোনো ডেটাবেজে মাইগ্রেশন চালাবে না।** শুধু ফাইল লিখবে; মালিক স্টেজিংয়ে চালাবে।

## সিক্রেট
কোনো key/secret/token কোডে, কমিটে, রিপোর্টে বা `VITE_` ভ্যারিয়েবলে নয়। সিক্রেট থাকবে Supabase Secrets / Vercel server env-এ। কোডে শুধু নাম (`Deno.env.get("R2_SECRET")`) থাকবে।

## যা আগে থেকেই ভালো (বদলাবে না)
`profiles.role` বদল ট্রিগারে আটকানো · NID/KYC প্রাইভেট `seller-kyc` বাকেট · `SECURITY DEFINER`-এ `search_path` · `audit_logs` append-only · ইউজার কনটেন্টে `dangerouslySetInnerHTML` নেই · `.env` গিট-ইগনোর।

## ফিক্সড সংখ্যা
- ভিডিও: **২৫ MB / ৬০ সেকেন্ড** (`src/lib/reelLimits.ts`), ডিবি backstop ৫০ MB। ১০০ MB করবে না (মালিকের সিদ্ধান্ত লাগবে)। বদলাতে হলে ক্লায়েন্ট + বাকেট + ডিবি তিন জায়গায় একসাথে।
- আউটপুট ৯:১৬, `1080x1920`।
- `reels.kind` = `product` (সেলার) / `content` (ইউজার)। মেট্রিক্স/মডারেশন/রিপোর্টে সবসময় `kind` দিয়ে ফিল্টার।

## অন্যান্য
- AdSense: Auto ads, Anchor, Vignette বন্ধ। **ফিডে অ্যাড বানাবে না** (৪.৩ মালিকের ম্যানুয়াল সিদ্ধান্ত)।
- কপিরাইটযুক্ত গান/ছবি নয়। আইনি কনটেন্টে "আমি আইনজীবী নই" নোট।
- ফেজের বাইরের কাজ বা অপ্রাসঙ্গিক রিফ্যাক্টর নয়।

## বাজেট (লিমিট বাঁচাতে)
- সর্বোচ্চ ~৪৫ টার্ন। পুরো রিপো পড়বে না: `Grep`/`Glob` দিয়ে টার্গেট ফাইল খুঁজে সেগুলোই পড়ো।
- ফেজ বড় লাগলে মূল অংশ শেষ করো, বাকিটা রিপোর্টে "বাকি কাজ"-এ লিখো। পরের ফেজ সেটা পড়বে।

## রিপোর্ট ফরম্যাট (`roadmap/reports/<ID>.md`, ≤ ৩০ লাইন)

5. বাকি কাজ (থাকলে)
6. মালিকের ম্যানুয়াল কাজ
